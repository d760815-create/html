📂 HTML 常用標籤字典

1. 網頁基本結構 (Document Structure)

標籤名稱用途說明
<html>網頁根元素，包含整個網頁內容。
<head>存放網頁後台資訊（如編碼、標題、CSS 連結）。
<title>定義網頁在瀏覽器分頁上顯示的標題。
<body>網頁可見內容的主要區塊。
<meta>定義網頁元數據（如 RWD 設定、關鍵字、編碼）。
<link>引入外部檔案（如 CSS 樣式表、網站圖示）。
<script>引入或撰寫 JavaScript 腳本。

2. 語意化區塊 (Semantic Elements)

標籤名稱用途說明
<header>網頁或特定區塊的頁首（頁頭導覽）。
<nav>定義導覽列連結的區塊。
<main>網頁的主要獨特內容（一個頁面僅限一個）。
<article>獨立、完整的文章、新聞或部落格內容區塊。
<section>一般性的分段主題區塊。
<aside>側邊欄、廣告或與主要內容間接相關的附帶資訊。
<footer>網頁或區塊的頁尾（版權宣告、聯絡資訊）。

3. 內容與文字格式 (Text Content)

標籤名稱用途說明
<div>無語意的區塊級標籤（常用於排版與分組）。
<span>無語意的行內級標籤（常用於設定局部文字樣式）。
<h1> ~ <h6>網頁標題，由大 (h1) 到小 (h6)。
<p>定義文字段落。
<br>強制文字換行。
<hr>產生一條水平分隔線。
<strong>粗體文字（具重要性語意，非單純視覺加粗）。
<em>斜體文字（具強調語意）。
