如何複製並執行？
  1. 按「複製完整 HTML」。
  2. 在 VS Code 建立空白檔案，貼上全部程式碼。
  3. 以 UTF-8 儲存為 index.html。
  4. 使用 Chrome、Edge 或 Safari 開啟該檔案。

不需另建 CSS／JS 檔案。亦可按「下載本頁 HTML」直接取得檔案。若瀏覽器限制剪貼簿，會自動選取全部原始碼，按 Ctrl+C／⌘C 即可。

複製內容從 <!DOCTYPE html> 到 </html>，不含省略段落。
